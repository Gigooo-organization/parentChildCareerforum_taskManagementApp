# 当日PCで10分の体験を確認する

実際に使うPCとテザリング回線で、スタッフ1人と参加者役1人が通して操作します。時計を使い、AIが間に合わない場合も10分で終えられるか確認してください。

## 開始前に用意する

- [ ] 当日使うmacOSのPCで依存関係をインストールする。
- [ ] 当日のAIを選び、そのPCでCLIへログインする。
- [ ] 実際のテザリング回線へ接続する。
- [ ] 以前の作品を残す場合は、`.booth/app/src`と`features.json`を別の保存先へコピーする。
- [ ] [READMEの起動手順](../README.md#起動する)で起動し、`http://127.0.0.1:5173/`を開く。
- [ ] ブルーの初期画面、3件の未完了タスク、自分のアイデアのカードがないことを確認する。

## 10分で通して操作する

| 経過時間 | 操作 | 確認する表示 |
| --- | --- | --- |
| 0〜1分 | 画面の目的を説明し、プレビューのタスクを1つチェックする | 完了チェックが付く |
| 1〜3分 | 色のカードとポイントのカードを作る | 選んだ色とポイントが反映され、カードが完成へ移る |
| 3〜5分 | 達成率とお祝いの仕様を選び、残りのタスクも完了する | 達成率と、選んだキャラクター・言葉のお祝いが出る |
| 5〜6分 | **つぎの目標を設定する**を押し、タスクを候補から追加する | 完了状態が戻り、選んだタスクが増える |
| 6〜8分 | 見出し変更の候補を入力欄へ入れ、「つぎに作るに追加」を押す。追加したカードの「作る」を押し、スタッフが内容を読み承認する | 承認前は変更されず、承認後に作成中、完了または失敗が表示される |
| 8〜9分 | 生成後の画面と、元のチェック・タスク追加を試す | 依頼した見出しと既存機能が使える。失敗時は元の画面が使える |
| 9〜10分 | 保存が必要ならコピーし、スタッフが**次の人へ**、**リセットする**を押す | 自分のアイデアのカード・タスク・機能・テーマ色が初期状態へ戻る |

AIが90秒で終わらない場合は、その結果を記録し、カタログで作った機能を試す説明へ切り替えます。待ち時間のために終了時刻を延ばさないでください。

## 回線切断と復帰を確認する

作品を保存してから、別の試行で確認します。

- [ ] サーバーを動かしたままテザリングを切り、色・ポイント・達成率・お祝いのカタログを操作する。
- [ ] カタログの反映とプレビュー操作が、回線なしでも続けられることを確認する。
- [ ] 回線を戻し、自由なお願いを1件だけ承認する。完了または期限内の失敗表示まで待つ。
- [ ] 承認しなかった依頼を取り消し、AIへ送られないことを確認する。
- [ ] 実行中に**次の人へ**を操作し、停止後に初期状態へ戻ることを確認する。
- [ ] 次の参加者役へ交代し、前のカードと作品が残っていないことを確認する。

復元できないエラーが出た場合は、スタッフがリセットします。リセットにも失敗した場合は、保存が必要なコードを退避してサーバーを再起動します。
